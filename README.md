# DouBao2.1API

把豆包网页版（豆包 2.1 的 lite / turbo / pro 三个档位）包装成一个 **OpenAI 兼容**的本地 API 服务，供支持自定义 base URL 的客户端使用。

顺便提供一个额度查看页面，可以看当前账号的用量百分比和重置倒计时。

> **本项目是个人学习性质的实验代码**，靠浏览器自动化驱动网页版前端，不是官方 API 的替代品，也不保证稳定。写得比较粗糙，很多地方是踩坑之后回填的补丁，仅供参考。

### 已知的硬性限制（请先确认能满足你的需求）

| 限制 | 说明 |
|---|---|
| **不支持 Function Calling / 工具调用** | 上游网页协议不做原生 tool_calls。参考项目用提示词注入 + 正则解析来模拟，作者自己也说明了不适合重度工具调用的场景。**所以本项目定位是文本/推理类后端。** |
| **吞吐很低** | 全程共用一个浏览器页面，请求必须串行排队，实际 QPS 上限约为 1。网页版本身就是串行的，所以并发请求会排队而不是并行。 |
| **token 用量是估算的** | 上游不返回 token 计数，本项目按字符数粗略估算，误差可能较大。 |
| **需要人工兜底** | 登录、人机验证（滑块 / 短信）必须在有界面的浏览器窗口里手动完成，无法全自动。 |
| **可能触发风控** | 请求太密集会被限流（实测短时间内连打十余次即触发）。本项目做了节流和冷却，但不能保证不被限流。 |
| **额度会耗尽** | 网页版按滚动时间窗计额度（当前时段 3 小时 + 近 7 天）。额度用完只能等重置或换账号。 |

## 功能

- OpenAI 兼容的 `POST /v1/chat/completions`，支持流式（SSE）与非流式
- `GET /v1/models` 列出可用模型
- 三个真实档位：`doubao-2.1-lite`、`doubao-2.1-turbo`、`doubao-2.1-pro`
- **额度查看页面**：当前时段（3 小时）用量百分比、重置倒计时、近 7 天用量、套餐到期时间
- 检测到人机验证时会拉起浏览器窗口并弹出系统通知，提示人工处理

## 多账号管理：预留了接口，但没有实现

这一节需要说清楚，避免误解。

**本项目目前只支持一个账号。** 涉及多账号的部分只做了最小限度的预留，**没有实现任何账号切换逻辑**：

- 浏览器会话绑定到「当前账号」的 `user-data-dir`（`DOUBAO_USER_DATA_DIR`）和显示名（`DOUBAO_ACCOUNT_LABEL`）
- 想换账号，只能改这两个环境变量后**重启服务**
- **没有**账号注册表、**没有**按账号的锁、**没有**额度耗尽或触发风控时的自动切换

之所以这样设计，是因为我的使用策略是**一个账号的额度完全用完，再换下一个**，而不是多个账号轮换使用。所以同一时刻只需要跑一个浏览器，不需要多实例。

真要实现自动切换的话，大致需要改两处：

1. `browser.py` 从单例改成「账号 → BrowserSession」的注册表
2. `server.py` 里的全局串行锁改成按账号的锁

另外提醒：**闲置较久的账号，登录态可能已经过期，切回去时需要重新扫码登录。**

## 工作原理（简述）

网页版的前端会用 JS 计算请求签名（`X-Bogus` / `a_bogus`），签名依赖页面运行时的环境指纹，**无法在 Python 侧复现**。所以本项目不去逆向签名算法，而是：

1. **复用浏览器里真实页面的请求能力**：在页面内部调用 `window.fetch` 发送请求，签名由页面自己完成
2. **请求模板来自真实抓包**：`templates/*.json` 是实际录制下来的请求（URL + 请求头 + 请求体），发请求时只替换用户输入和几个会过期的字段
3. **模型切换靠改请求体，不靠点界面**：每个档位对应不同的 `model_item_key` / `need_deep_think`。点界面切换非常脆弱——一旦弹出人机验证浮层就会盖住整个页面，什么都点不动。

顺带的好处是：借页面的 `fetch` 发请求，Cookie、UA、TLS 指纹等风控会看的因素都自然吻合。

额度查看的做法类似：**新开一个标签页**导航到官方额度页，在旁边监听接口响应拿到数据，抓完关掉标签。实测这样不会打断正在进行的对话。

## 安装

需要 **Python 3.10+**，以及本机安装的 Chrome 或 Edge。

### 方式一：Windows 一键脚本（推荐）

```
start.bat
```

首次运行会自动完成：创建 `.venv` 虚拟环境 → 安装依赖 → 下载 Chromium。

指定端口：

```
start.bat --port 8899
```

> 依赖全部装在项目目录下的 `.venv` 里，**不会安装到系统 Python，也不修改任何全局环境变量**。

### 方式二：手动（其他系统，或想自己控制）

Windows：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m playwright install chromium
```

macOS / Linux：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
```

> 说明：`playwright install chromium` 会把浏览器下载到用户目录下的共享缓存（Windows 是 `%LOCALAPPDATA%\ms-playwright`），这是 Playwright 自身的行为，不属于"污染全局环境"，也不会影响其他 Python 项目。
>
> 如果下载 Chromium 失败，可以跳过这一步——本项目会**自动回退使用本机已安装的 Chrome / Edge**。

## 使用

### 1. 登录（必做，且需要人工操作）

```
login.bat
```

会打开一个浏览器窗口，扫码登录。如果出现人机验证，需要手动完成。

### 2. 抓取请求模板（必做）

```
capture.bat
```

会依次切换三个模型各发一次探测请求，把真实的请求模板录到 `templates/` 下。

> 这一步是**必须**的：API 依赖这些模板。豆包前端改版后也需要重新抓一次。

### 3. 启动服务

```
start.bat
```

默认监听 `http://127.0.0.1:8787`。

### 4. 使用

OpenAI 兼容的 base URL：

```
http://127.0.0.1:8787/v1
```

模型名可以是 `doubao-2.1-lite` / `doubao-2.1-turbo` / `doubao-2.1-pro`。

API Key 默认不校验（仅本机自用）。如需启用，设置 `DOUBAO_API_KEY`。

### 5. 查看额度（可选）

浏览器打开：

```
http://127.0.0.1:8787/admin
```

显示当前时段（3 小时窗口）已用百分比与重置倒计时、近 7 天用量、套餐及到期时间。

> 网页版额度按**滚动时间窗**计算（当前时段 3 小时 + 近 7 天），不是 token 余额。
> 抓取一次约需 7 秒（要开新标签页导航），所以默认缓存 60 秒。

## 配置

配置通过**环境变量**读取，也支持项目根目录下的 `.env` 文件。

`start.bat` 首次运行会从 `.env.example` 复制一份 `.env`，**直接改 `.env` 就能生效**（改完重启服务）。

优先级：**已有的系统环境变量 > `.env`**。也就是说 `.env` 里的值不会覆盖你已经在系统里设好的变量，方便临时覆盖：

```bat
set DOUBAO_PORT=8899
start.bat
```

> `.env` 只影响本进程，不会写入系统环境变量。

主要变量（完整清单见 `.env.example`）：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DOUBAO_HOST` | `127.0.0.1` | 监听地址 |
| `DOUBAO_PORT` | `8787` | 监听端口 |
| `DOUBAO_API_KEY` | 空 | 留空则不校验 |
| `DOUBAO_USER_DATA_DIR` | `~/.DouBao2.1API/browser` | 登录态持久化目录 |
| `DOUBAO_ACCOUNT_LABEL` | `default` | 当前账号显示名（仅展示用） |
| `DOUBAO_HEADLESS` | `false` | **必须为 false**，人机验证需要人工在窗口里操作 |
| `DOUBAO_BROWSER_EXECUTABLE` | 空 | 留空则自动探测本机 Chrome / Edge |
| `DOUBAO_MIN_INTERVAL` | `3.0` | 两次上游请求的最小间隔（秒），调小容易触发风控 |
| `DOUBAO_RATE_LIMIT_COOLDOWN` | `60` | 命中限流后的冷却秒数 |
| `DOUBAO_REQUEST_TIMEOUT` | `180` | 单请求超时（秒） |
| `DOUBAO_QUOTA_CACHE_TTL` | `60` | 额度缓存秒数 |

### 换账号

```bat
set DOUBAO_USER_DATA_DIR=C:\Users\你\.DouBao2.1API\acc-b
set DOUBAO_ACCOUNT_LABEL=acc-b
start.bat
```

然后重新跑 `login.bat` 登录新账号。额度用完时用这个方式手动切换。

## 接口

| 端点 | 说明 |
|---|---|
| `GET /health` | 健康检查 |
| `GET /v1/models` | 模型列表 |
| `POST /v1/chat/completions` | 对话补全（流式 / 非流式） |
| `GET /v1/upstream/models` | 上游档位与模板状态（排查用） |
| `GET /admin` | 额度查看页面 |
| `GET /admin/quota` | 额度 JSON（`?refresh=1` 强制重抓） |
